# Stage 8 updater code — 2026-10-24

## Scope and status

Updater CODE is implemented behind compile-time configuration; the production
channel is still disabled and real-update acceptance is pending. This does not
change roadmap scope or acceptance gates. It does not mark all feasible work or
the roadmap complete.

- Official `tauri-plugin-updater` 2.14.0; narrow native status/action commands,
  no added updater/process webview capabilities or CSP expansion.
- Four build-only public configuration values validated by the build script and
  runtime's embedded constants. Missing-all disables; partial/bad values fail
  the build. No runtime endpoint/key/channel overrides.
- Native serialized state and duplicate-operation guard, verified in-memory
  download, separate install and restart, discard before install, sanitized
  failure codes, explicit retry, progress status recovery across Settings remount.
- Explicit check/download/install/restart confirmations. No user cancellation
  during active operations is promised. Installer interruption is not supported.
- HTTPS-only client including redirects, signature verification, signed-version
  binding and default newer-version policy. Windows installer exits with automatic relaunch disabled;
  Linux/macOS restart requires a separate confirmation.
- Existing auth/pack native implementations remain unchanged; install/restart
  explicitly close Core sessions before potentially exiting the process.
